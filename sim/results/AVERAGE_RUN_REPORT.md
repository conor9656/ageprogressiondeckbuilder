# Average run reports

Goal: see how often gold / Science / Civics / troop upgrades / specials / packs land after each fight.

Generated by `sim/avg_run_report.py` (N=250 / strategy, eras 1–3, Defence 500/800/2000).

## Executive summary — upgrade stack is thin

Typical **S3 Battle Line** survivor after each Ancient Capital (fight 3):

| Resource / upgrade | Average after E1 Capital |
|---|---|
| Gold on hand | ~40 |
| Faith | ~14 |
| Science level-ups taken | **~1.4** |
| Civic level-ups taken | **~1.4** |
| Class tiers (M/R/C/S/B) | **1.6 / 1.3 / 1.1 / 1.1 / 1.2** |
| Blueprints owned | **~1.4** |
| Doctrines owned | **~0.8** |
| Policies owned | **~0.7** |
| Special (edition) units | **~0.24** |
| Promoted cards | ~0.9 |
| Formation levels total | **~0.2** |

After **Classical Capital** (among the ~9% who get there): sci levels ~3.0, still only ~1.8 Blueprints / 1.0 Doctrine / 1.4 Policies, Melee maybe tier **2.3**.

**Per-fight cadence (S3):**
- Village: only **~25%** get a Science level-up; troop upgrade on ~23% of runs
- Town: **~75%** Science level-up (main spike); troop upgrade ~63%
- Capital: ~40% Science level-up
- Special edition units: only **~5–8%** of fights gain one
- Blueprint find rate falls as slots fill / gold goes to units (~50% → ~10% by mid Classical)

This is why Medieval fails: by the time Capital HP is 5000, the average stack is still “a couple of tier-ups and one Blueprint,” not a multiplier engine. Supports the plan to **increase Science/Faith/Builder/troop upgrade frequency** (more bar fills, richer packs, or higher reward stubs).
