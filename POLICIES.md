# Policies — full draft pool

Culture / civics rewards. **Always on** while equipped (Balatro-joker slot energy).  
Original Ages designs. Numbers are provisional. Rarities: **C / U / R**.

## Design modes (from scoring-pattern study)

| Mode | Meaning | Ages use |
|---|---|---|
| **Flat** | Same bonus all run | `Melee +4 Might` |
| **Conditional** | Flat, but only if shape/class/context | `+8 Might on Battle Line` |
| **Multiplier** | ×Might or ×Momentum on the formation | Rare; ×Mom is very strong (damage is Might×Mom) |
| **Scaling** | Grows from run events | Show current value in UI |
| **Economy** | Gold / Science / Culture / Faith / interest | Enables shops, not raw damage |
| **Utility** | Hand size, Regroups, slots, reshapes rules | Consistency |

**Scaling safety:** prefer growth on *settlement won* or *specific formation once per settlement*, not every Assault, unless the step is tiny. Cap or soft-cap noted where needed.

**OP red flags:** permanent ×Momentum ≥1.5 on all formations; uncapped +Mom per Assault; retrigger + multiplier stacked early.

Strategies: S1 Wallbreakers · S2 Thin Legion · S3 Battle Line · S4 Builder · S5 Faith · S6 Science

## Balance watchlist

- **P13 + P03 + thin Cavalry** can spike early — if needed, drop Horse Breeding to +4.
- **P30 / P31** are the only broad ×Mom tools; do not add more without caps.
- **P11 Conscription + Veteran Edition + P34** interactions: test before adding more retriggers.
- Scaling Policies should display `Currently: +X` in UI.
